# Ponderada CC08 - Tato

**Autor:** Yan Dimitri Kruziski

Análise de arquitetura, pipeline, concorrência e deadlock para uma pulseira sensorial destinada a pessoas com deficiência visual.

## Como executar a questão A4

É necessário ter Python 3 instalado. A partir da raiz do repositório, execute cada versão com um único comando:

```bash
python3 ponderada/codigo/versao1.py
python3 ponderada/codigo/versao2.py
python3 ponderada/codigo/versao3.py
```

Cada programa usa o buffer individual `N = 6` e executa 20.000 amostras por padrão. Não há dependências externas.
